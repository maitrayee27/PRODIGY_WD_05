# 🌤️ Weather App

A beginner-friendly Weather App built using HTML, CSS, and JavaScript.

## 📌 About

This project was created as part of Task-05 of the Prodigy InfoTech Web Development Internship.

The Weather App fetches weather information based on a user-entered city or the user's current location.

## ✨ Features

- 🔍 Search weather by city
- 📍 Get weather using current location
- 🌡️ Display current temperature
- ☁️ Display weather condition
- 💧 Display humidity
- 💨 Display wind speed
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API
